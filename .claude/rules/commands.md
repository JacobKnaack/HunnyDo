# Project Commands

```bash
npm run dev # Runs the project in development mode
npm run start # Does the same as `npm run dev`
npm run build # Builds the project for production
npm run preview # Builds the project for previewing
npm run astro # Runs the Astro CLI
npm run test # Runs the test script
npm run publish:legal # Publishes the legal documents and notifies API of changes
```
